# Kineplanet

Rediseño del sitio de kinesiología a domicilio de Kineplanet. La portada está en index.html.

Abre index.html directamente o ejecuta:

    node scripts/serve.mjs

Para generar y revisar la versión estática:

    node scripts/build.mjs
    node scripts/serve.mjs dist

Edita index.html y los archivos de src. Las imágenes y fuentes están en public.
